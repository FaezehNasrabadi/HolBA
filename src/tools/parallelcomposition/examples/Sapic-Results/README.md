## Sapic Models and Results 
---------------------------------------------------

This directory contains files of extracted Sapic models of each protocol we analyzed and the results from executing the extracted model with the Sapic toolchain.

To view the results we obtained from the Sapic toolchain backends, refer to `_attack_*` or `-result.txt` files.

### Files organization:

- `*.spthy`:
  * Our SAPIC file
  * Attack traces
- `*.pv`:
  * Exported ProVerif file from our SAPIC file
- `*.dps`:
  * Exported Deepsec file from our SAPIC file
